Has trobat un error?

Si has trobat una paraula mal transcrita, una rima que no hi hauria de ser o qualsevol altra cosa que no rutlla, explica'ns-ho i ho corregirem tan aviat com puguem.

Si ho prefereixes, també ens pots escriure directament a hola@rimador.cat.

Col·labora directament a GitHub!

El Rimador català és un projecte de codi obert. Si saps programar o vols proposar una millora directament al codi font o a les dades del diccionari, pots fer una proposta de canvi (Pull Request) al nostre repositori de GitHub.

Com fer-ho pas a pas:

  1. Fes una ForkVes al nostre repositori i fes clic a "Fork" per tenir-ne una còpia al teu compte.
  2. Fes els teus canvisPots modificar el codi directament des de la web de GitHub, o bé descarregar la fork al teu ordinador fent git clone si et resulta més còmode. Modifica el codi, el diccionari o el que consideris que ens pots ajudar a millorar.
  3. Desa-ho fent CommitAfegeix una descripció clara del que has arreglat o millorat i fes el Commit. Si fas servir la terminal, pots fer-ho amb git commit -m "Descripció" i després un git push.
  4. Obre la Pull RequestTorna a la pàgina principal del repositori a GitHub i fes clic a "New pull request" perquè les modificacions ens arribin. Ho revisarem i ho integrarem al projecte!

A rimar!
